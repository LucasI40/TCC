Como criar um Room?

Para criar um Room, você precisa enviar um modelo de sala.
O modelo de sala é um arquivo JSON que contém as informações da sala.

O arquivo JSON deve seguir o seguinte padrão:

{
"name": "Nome da sala",
"description": "Descrição da sala",
"imagem":{
"src": "Imagem da sala",
"alt": "Alt da imagem"
},
"roles":{
"role1":[ "capacidade1", "capacidade2", ..., "capacidadeN" ],
"role2":[ "capacidade1", "capacidade2", ..., "capacidadeN" ],
...
"roleN":[ "capacidade1", "capacidade2", ..., "capacidadeN" ],
}
}

O campo "roles" é opcional. Se não for informado, o Room será criado sem roles.
As capacidades são as seguintes: 'send_video', 'recv_video', 'send_audio',
'recv_audio', 'send_string', 'recv_string'
