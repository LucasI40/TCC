Como criar um arquivo JSON?

O que é JSON?

JSON significa JavaScript Object Notation.

É uma forma de guardar informações de maneira organizada,
como se fosse uma tabela, mas em texto.

Você pode pensar nele como uma caixinha de dados, usada por sites,
aplicativos e sistemas para trocar informações.

Exemplo:

Um aplicativo pode guardar os dados de um usuário assim:

{
"nome": "João",
"idade": 20,
"email": "joao@example.com"
}

O que você precisa?

  • ✅ Um bloco de notas (ou qualquer editor de texto simples)
  • ✅ Saber salvar arquivos no computador
  • ✅ Ter curiosidade!

Criando seu primeiro arquivo JSON

Passo 1 – Abra o Bloco de Notas

No Windows: pressione Win + R, digite notepad e aperte Enter.

No Mac: abra o TextEdit.

Passo 2 – Escreva os dados

Escreva os dados que você quer guardar no arquivo. Por exemplo:

{
"nome": "João",
"idade": 20,
"email": "joao@example.com"
}

Explicando:

{ } → significa início e fim do objeto (do “pacote de informações”)

"nome", "idade", "cidade" → são os nomes das informações (chamados chaves ou keys)

"Ana", 30, "São Paulo" → são os valores dessas informações (values)

Passo 3 – Salve o arquivo

  • Vá em Arquivo → Salvar como...
  • No campo Nome do arquivo, digite: dados.json
  • Em Tipo, escolha Todos os arquivos (ou equivalente)
  • Certifique-se de que o nome termina com .json. Clique em Salvar
